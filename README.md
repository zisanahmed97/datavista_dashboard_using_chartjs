# Sales Analytics Dashboard

A modern, responsive Sales Analytics Dashboard built with **HTML, CSS, and Chart.js** to visualize sales performance through interactive charts and key business metrics.

### Features
- KPI cards for total sales, average sales, best-performing month, and growth rate.
- Interactive line, bar, and doughnut charts.
- Monthly sales filtering and dynamic data updates.
- Business insights and detailed sales reports.
- CSV export functionality.
- Responsive design for desktop, tablet, and mobile devices.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- Font Awesome

### Getting Started
1. Clone or download the repository.
2. Ensure `index.html` and `style.css` are in the same directory.
3. Open `index.html` in your browser.
4. Customize the sample sales data in the JavaScript section to analyze your own data.

**Note:** This project uses sample data for demonstration purposes.
